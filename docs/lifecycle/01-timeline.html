Why two graphs? resume_outline replays the real ADK app so the paused tool call can be answered. research_phase and revision build a new App against restored state (pipeline.py:319-343) — that is a restart, not a resume. ADK's own resume becomes unreliable once the holding process dies, but the state is reliably restorable from Postgres, so the system degrades from "resume" to "rerun".
